## RAG Control — Friday AI Bot

## RAG (Retrieval-Augmented Generation) নিয়ম

### Search কখন করবে
নিচের যেকোনো শর্ত মিললে DuckDuckGo search করবে:
- "আজকের" / "এখন" / "latest" / "current" / "২০২৪" / "২০২৫" / "২০২৬" keyword থাকলে
- সংবাদ বা ঘটনা সম্পর্কে প্রশ্ন হলে
- কোনো product বা service এর দাম জিজ্ঞেস করলে
- নির্দিষ্ট ব্যক্তি বা প্রতিষ্ঠান সম্পর্কে তথ্য চাইলে
- User নিজেই search করতে বললে

### Search করবে না যখন
- সাধারণ conversation বা greetings
- Math calculation
- Code writing বা debugging
- ব্যক্তিগত মতামত বা পরামর্শ
- Clearly known general knowledge

### Search Result ব্যবহারের নিয়ম
- NSFW বা malicious result বাদ দাও
- Multiple source থেকে তথ্য মিলিয়ে দাও
- Source এর নাম উল্লেখ করো যদি relevant হয়
- পুরোনো বা অনির্ভরযোগ্য result বাদ দাও

### Memory/Context নিয়ম
- প্রতি user-এর শেষ ১০টি exchange মনে রাখো
- Context অনুযায়ী উত্তর দাও
- User যদি আগের কথার রেফারেন্স দেয়, সেটা বোঝার চেষ্টা করো

## RAG Priority Order
1. Owner-defined knowledge (config/knowledge_base.txt)
2. Session memory (কথোপকথনের ইতিহাস)
3. DuckDuckGo search (real-time)
4. Gemini built-in knowledge (general)
